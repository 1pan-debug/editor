# Flutter Code Editor

一个使用 Flutter 构建的代码编辑器项目，计划从基础文本编辑与文件操作开始，逐步加入查找、C++/Python 语法高亮和 Vim 模式。

## 当前状态

阶段 1 至阶段 5 已实现。编辑器支持文本输入、选择、复制/剪切/粘贴、撤销/重做、全选、光标位置显示，以及新建、打开、保存和另存为。打开文件、覆盖文档和退出时会保护未保存修改。查找栏支持输入即定位、循环遍历匹配项、大小写开关和无匹配提示，快捷键为 Ctrl+F、F3、Shift+F3。C++ 与 Python 文件按扩展名自动启用语法高亮（关键字、注释、字符串、数字、预处理指令/装饰器等），也可通过工具栏语言菜单手动切换或回到纯文本。工具栏提供 Vim 模式开关，状态栏实时显示当前 Vim 模式。当前首发目标为 Windows 桌面，其他平台尚未验收；界面采用 Material 3 与 Google 蓝色系主题。

## 已实现的 Vim 命令

Vim 模式为简化子集，不宣称完整兼容 Vim：

- 模式：普通模式、插入模式、命令行模式；`i`/`a`/`I`/`A`/`o`/`O` 进入插入，`Esc` 返回普通模式，`:` 打开命令行。
- 移动：`h`、`j`、`k`、`l`（行内/行间移动，到行首行尾即停）、`0`、`$`；`Enter`、退格、空格分别映射为下移、左移、右移。
- 修改：`x`（删除光标处字符）、`dd`（删除整行）、`yy`（复制整行）、`p`（粘贴，区分行级/字符级）、`u`（撤销，走编辑器撤销历史）。
- 命令行：`w` 保存、`q` 关闭当前文档（脏文档走未保存保护）、`q!` 放弃修改并关闭、`wq` 保存后关闭。
- 寄存器为编辑器内部实现（不经系统剪贴板）；连续快速的 Vim 命令可能被 Flutter 撤销历史的 500ms 节流合并为一步撤销。

文件按严格 UTF-8 读取，保留 UTF-8 BOM；编辑时统一使用 LF，保存时沿用打开文件的首个换行符格式。无效 UTF-8、读写失败和文件选择取消不会静默替换或丢弃当前文档。查找按字面量子串处理，不支持整词匹配和正则表达式；语法高亮为轻量正则实现，不含完整词法分析。详细进度见 [TODO.md](TODO.md)。

## 计划功能

- 编辑文本，并提供基础编辑操作。
- 打开、保存和另存为文本文件，并提示未保存的修改。
- 在当前文档中查找文本。
- 为 C++ 和 Python 提供语法高亮。
- 提供可启用和关闭的 Vim 风格编辑模式。

## 开发环境

- Flutter SDK（版本要求见 `pubspec.yaml`）
- Dart SDK（版本要求见 `pubspec.yaml`）

## 开始运行

```sh
flutter pub get
flutter run
```

如需选择特定运行设备，可先执行 `flutter devices`，再使用 `flutter run -d <设备 ID>`。

## 验证

运行 Flutter 测试：

```sh
flutter test
```
