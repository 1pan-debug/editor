# Flutter Code Editor

一个使用 Flutter 构建的 Windows 桌面代码编辑器，支持基础文本编辑、文件操作、查找、C++/Python 语法高亮和简化版 Vim 模式。

## 当前状态

阶段 1 至阶段 5 已全部实现，包含：文本编辑与撤销/重做、新建/打开/保存/另存为、未保存修改保护、文档内查找、C++/Python 语法高亮和简化版 Vim 模式（命令范围见下文）。

验证情况：`flutter analyze` 无问题，97 项单元与组件测试全部通过，Windows Debug 构建成功。主要用户流程（编辑、文件操作、未保存保护、查找、高亮、Vim 命令）已由组件测试覆盖；在实际设备上的手动验收仍待执行。

## 支持平台

首发目标为 Windows 桌面。macOS/Linux 代码路径已就绪但未验收；Web 与移动端的文件访问体验未验证。

## 已实现的 Vim 命令

Vim 模式为简化子集，不宣称完整兼容 Vim：

- 模式：普通模式、插入模式、命令行模式；`i`/`a`/`I`/`A`/`o`/`O` 进入插入，`Esc` 返回普通模式，`:` 打开命令行。
- 移动：`h`、`j`、`k`、`l`（行内/行间移动，到行首行尾即停）、`0`、`$`；`Enter`、退格、空格分别映射为下移、左移、右移。
- 修改：`x`（删除光标处字符）、`dd`（删除整行）、`yy`（复制整行）、`p`（粘贴，区分行级/字符级）、`u`（撤销，走编辑器撤销历史）。
- 命令行：`w` 保存、`q` 关闭当前文档（脏文档走未保存保护）、`q!` 放弃修改并关闭、`wq` 保存后关闭。
- 寄存器为编辑器内部实现（不经系统剪贴板）；连续快速的 Vim 命令可能被 Flutter 撤销历史的 500ms 节流合并为一步撤销。

## 已知性能边界

- 编辑区无虚拟化与行号渲染，超大文件（数 MB 级）的输入与滚动可能变慢。
- 语法高亮在每次内容变化时全量重建（万行样例耗时在测试上限内），超大文件的逐键高亮可能滞后。
- 查找为全文正则扫描，每次查询 O(n)；匹配列表一次性物化，超大文档的首次查询可能有可感知延迟。

## 文件约定

文件按严格 UTF-8 读取，保留 UTF-8 BOM；编辑时统一使用 LF，保存时沿用打开文件的首个换行符格式。无效 UTF-8、读写失败和文件选择取消不会静默替换或丢弃当前文档。查找按字面量子串处理，不支持整词匹配和正则表达式；语法高亮为轻量正则实现，不含完整词法分析。详细进度见 [TODO.md](TODO.md)。

## 计划功能

- 编辑文本，并提供基础编辑操作。（已实现）
- 打开、保存和另存为文本文件，并提示未保存的修改。（已实现）
- 在当前文档中查找文本。（已实现）
- 为 C++ 和 Python 提供语法高亮。（已实现）

## 开始运行

```sh
flutter pub get
flutter run
```

如需选择特定运行设备，可先执行 `flutter devices`，再使用 `flutter run -d <设备 ID>`。

## 验证

运行 Flutter 测试：

```sh
flutter test
```
