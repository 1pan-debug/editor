# Flutter Code Editor

一个使用 Flutter 构建的代码编辑器项目，计划从基础文本编辑与文件操作开始，逐步加入查找、C++/Python 语法高亮和 Vim 模式。

## 当前状态

阶段 1、阶段 2 已实现。编辑器支持文本输入、选择、复制/剪切/粘贴、撤销/重做、全选、光标位置显示，以及新建、打开、保存和另存为。打开文件、覆盖文档和退出时会保护未保存修改。当前首发目标为 Windows 桌面，其他平台尚未验收；界面采用 Material 3 与 Google 蓝色系主题。

文件按严格 UTF-8 读取，保留 UTF-8 BOM；编辑时统一使用 LF，保存时沿用打开文件的首个换行符格式。无效 UTF-8、读写失败和文件选择取消不会静默替换或丢弃当前文档。查找、语法高亮和 Vim 模式尚未实现。详细进度见 [TODO.md](TODO.md)。

## 计划功能

- 编辑文本，并提供基础编辑操作。
- 打开、保存和另存为文本文件，并提示未保存的修改。
- 在当前文档中查找文本。
- 为 C++ 和 Python 提供语法高亮。
- 提供可启用和关闭的 Vim 风格编辑模式。

## 开发环境

- Flutter SDK（版本要求见 `pubspec.yaml`）
- Dart SDK（版本要求见 `pubspec.yaml`）

## 开始运行

```sh
flutter pub get
flutter run
```

如需选择特定运行设备，可先执行 `flutter devices`，再使用 `flutter run -d <设备 ID>`。

## 验证

运行 Flutter 测试：

```sh
flutter test
```
